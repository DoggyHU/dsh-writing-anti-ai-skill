# Replacements Quick Reference

Fast lookup for common AI vocabulary → natural alternatives. This table is meant to be scanned during Pass 1 (Scan), not read cover-to-cover.

---

## 反映了 + Summary → Delete or Rewrite

The "反映了" construction is the most common paragraph closer in AI-written Chinese reports. It introduces no new information — it just signals "here comes the summary."

| Pattern | Action |
|---------|--------|
| 反映了……的多样性/复杂性/差异性 | Delete. The data already shows this. |
| 反映了……的显著成效/积极作用 | Delete or replace with factual outcome. |
| 反映了……之间的关联/关系 | Replace with "与……有关" or delete. |

## Filler Phrases → Delete

Delete the phrase. Keep what follows.

| Pattern | |
|---------|-|
| 值得注意的是， | Delete |
| 需要强调的是， | Delete |
| 需要指出的是， | Delete |
| 众所周知， | Delete |
| 不可否认的是， | Delete |
| 毋庸置疑， | Delete |
| 换句话说， | Delete |
| 也就是说， | Delete |
| 总体而言， | Delete |
| 从某种程度上说， | Delete |
| 基于……的事实 | Delete; rewrite with 因为 or restructure |
| 在……的背景下 | Delete; start the sentence directly |
| 在当今快速发展的……背景下 | Delete |
| 随着……的不断发展 | Delete |

## Section-Head Slogan Pairs → Delete Second Clause

Section headings that use comma-separated slogan pairs should be collapsed.

| Before | → | After |
|--------|---|-------|
| 优化XX，促进XX | → | (keep first 2-4 chars or rewrite) |
| 推进XX，提升XX | → | (keep first 2-4 chars or rewrite) |
| 加强XX，推进XX | → | (keep first 2-4 chars or rewrite) |
| 做强XX | → | (delete or rewrite as noun) |
| 优化全域XX格局 | → | (delete heading, merge into text) |

## Condensed Parallel Slogan Items → Collapse

Multi-item parallel frameworks with a shared prefix. Delete the prefix/label and merge into a paragraph.

| Before | → | After |
|--------|---|-------|
| 因土适种：... | → | 种植布局上，... |
| 因土适种 / 因土施肥 / 因制养地 / 因水管护 / 因品提质 | → | (collapse into one paragraph, delete labels) |

## 方针 → Delete

"方针" is a closing marker in AI-generated recommendation sections.

| Before | → | After |
|--------|---|-------|
| 提出……的利用方针 | → | 建议…… |
| 坚持……的发展方针 | → | (delete or be specific) |
| 遵循……的指导方针 | → | (delete) |

## Overused Causal Connectors → Downgrade or Delete

| Word | → | Natural |
|------|---|---------|
| 核心（核心载体/核心区域） | → | 主要 / 重点 |
| 关键（关键因素/关键机制） | → | 重要 / (delete) |
| 主导（主导因素/主导地位） | → | 主要 |
| 根本（根本原因/根本成因） | → | 主要 / 重要 / (delete) |
| 突出（问题突出/特征突出） | → | 明显 / (delete if data supports the claim) |
| 日趋突出 | → | 更加明显 / 加剧 |
| 严重（严重偏低/严重缺乏） | → | (delete; grading level already shows severity) |
| 急剧（急剧下降/急剧上升） | → | 下降 / 上升 (let the number speak) |
| 极度（极度匮乏/极度稀缺） | → | (delete) |
| 较为（较为复杂/较为现实） | → | (delete, or use the absolute form) |
| 相对（相对较好/相对较低） | → | (delete unless making an explicit comparison) |
| 十分（十分突出/十分重要） | → | (delete) |

## Value-Judgment Adjectives → Delete

Remove these unless they carry specific, measurable meaning:

| Adjective | Keep if... | Otherwise |
|-----------|-----------|-----------|
| 重要的 | it's a named concept (重要河流) | Delete |
| 著名的 | it affects identification | Delete |
| 优良的 | it's a technical grade (优良品种) | Delete |
| 完善的 | it's a defined standard | Delete |
| 严格的 | there's a specific standard cited | Delete |
| 充分的 | it's a legal threshold | Delete |
| 深刻的 | — | Delete |
| 丰富的 | it's a measurable quantity | Delete |
| 显著的 | p < 0.05 | Delete |
| 关键的 | it's a named component | Delete |
| 重大的 | — | Delete |
| 突出的 | — | Delete |
| 良好的 | it's a defined classification grade | Delete |
| 优越的 | — | Delete |
| 优异的 | it's a technical grade | Delete |
| 独特的 | it genetically distinguishes a named variety | Delete |
| 宝贵的 | — | Delete |
| 先进的 | — | Delete |

## English → Clean

| Before | → | After |
|--------|---|-------|
| serves as a testament to | → | shows |
| plays a crucial role in | → | is part of / contributes to |
| stands as a reminder of | → | reminds us that |
| highlights the importance of | → | shows why ... matters |
| ensures that | → | makes sure / (restructure) |
| Moreover / Furthermore | → | (delete or "And") |
| Additionally | → | (delete or "Also") |
| It is important to note that | → | (delete) |
| Due to the fact that | → | Because |
| In order to | → | To |
| Despite the challenges | → | (describe the specific challenge, or delete) |

## Usage

Load this file once at the start of Pass 1. Scan the text for matches in the left column. For each match, apply the right column action.

**Priority**: Filler phrases and AI vocabulary (必杀) > value-judgment adjectives (几乎必杀) > English replacements (context-dependent).
